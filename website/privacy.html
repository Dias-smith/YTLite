Privacy Policy

Last updated: November 15, 2026

This Privacy Policy applies to the mobile application Mixtube for iOS and Android (product name Mixtube; some technical identifiers may still use the historical name “YTLite”). It explains what information we collect, how we use it, how we store and share it — including Google user data obtained through Google APIs — and the choices you have. We do not sell your personal data.

Application home page: https://www.ytlite.cc/ (public; no login required to read about the app).

1. Who we are

Mixtube is a music-first online video player. You can browse and play online video, manage a personal library, optionally sync when signed in, and optionally import your own audio files (including Google Drive via Google’s official file picker) for playback on your device.

Privacy contact: diasjayanthasumith@gmail.com. Support: https://www.ytlite.cc/support.html.

2. Information we process

  • Account data. If you sign in with Sign in with Apple or Google (via our backend provider Supabase), we may store identifiers needed for authentication and profile display (user id, display name, email when provided, avatar URL). Apple may share a private relay email if you use Hide My Email.
  • Library & preferences. Playlists, likes, history, followed channels, imported local tracks metadata, language, and theme settings may be stored on device and, when you are signed in, synced to your Mixtube account.
  • Local media you import. Audio/video files you import (from Files, Photos, Wi‑Fi transfer, NAS/WebDAV, or Google Drive via Google’s file picker) are copied to on-device storage for offline playback. Those file bytes are not uploaded to our servers.
  • Google user data — Sign-In / YouTube (optional). When you sign in with Google and grant access, we may request:
    • OpenID sign-in scopes: openid, email, profile
    • https://www.googleapis.com/auth/youtube.readonly — to view subscriptions, playlists, and liked videos linked to your Google account so Mixtube can display them in-app. We do not post, upload, delete, or modify that content.
  • Google Drive import (optional, separate from YouTube sign-in). When you choose Import → Google Drive, Mixtube requests only https://www.googleapis.com/auth/drive.file and opens Google’s official file picker so you can select specific audio/video files. Access is limited to files you pick with the app (not your entire Drive). Selected files are downloaded and copied into the on-device Imported library only; we do not upload those bytes to our servers, and we do not request drive.readonly or other broad Drive scopes. This Drive consent is separate from Google Sign-In used for YouTube library display.
  • Other local / cloud file import. You may also import via the system Files picker (for example iCloud Drive), Photos, Wi‑Fi transfer, or NAS/WebDAV. Those paths do not use Google Drive API scopes. Files are copied into the on-device Imported library only.
  • Advertising (iOS). We use Google AdMob for ads (app-open, interstitial, and user-initiated rewarded ads). AdMob may process device advertising identifiers and related signals under your consent and platform settings (UMP / ATT where required). AdMob is separate from YouTube OAuth library data.
  • Analytics & diagnostics. Firebase Analytics (aggregated usage) and Crashlytics (crash/performance) may run in release builds to improve the product.
  • Device / technical data. Standard app operation may involve device type, OS version, language, and network errors needed to run and debug the service.

3. How we use information

We use the information above only to:

  • Provide sign-in, playback, library, sync, and import features;
  • Display Google-linked YouTube library surfaces you authorize (youtube.readonly);
  • Let you import audio/video you pick via the system Files app and other local import paths, storing copies only on your device;
  • Show ads where enabled, measure product usage, and fix bugs;
  • Respond to support or legal requests when required.

We do not sell personal information or Google user data. We do not use Google user data (YouTube) for advertising, credit decisions, or to train / improve generalized machine-learning or AI models. We do not use Google APIs to create or distribute AI-generated non-consensual intimate imagery (AI NCII).

4. Google user data — access, use, storage, and sharing (Limited Use)

Our use of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements, and (for Drive) the Google Workspace API user data and developer policy.

4.1 What we access

  • YouTube (readonly): metadata needed to show your subscriptions, playlists, and liked videos inside Mixtube.
  • Drive (readonly): file list metadata (name, id, mime type, size) for eligible audio/video files, and file content only for items you explicitly import.

4.2 How we use it

  • YouTube data → in-app display of your library shelves.
  • Drive data → user-initiated import of selected files into the local “Imported” library for playback on that device.

4.3 How we store it

  • OAuth access tokens for Google APIs are stored on the device only (app local storage) and are not uploaded to Supabase or other Mixtube servers.
  • Drive file bytes you import are stored in the app’s on-device media store. They are not synced to our cloud backend.
  • Basic Google profile fields used for Mixtube account identity may be stored in Supabase for authentication and sync of Mixtube library data (not Drive file contents).

4.4 How we share / disclose it

  • Google APIs: the app sends your device-held access token to Google to perform the authorized read-only requests.
  • Supabase: account profile fields for auth/sync as described above — not Drive file content, not YouTube OAuth tokens.
  • Firebase / AdMob / Apple: analytics, crashes, ads, or Apple sign-in as described elsewhere; these are not used to sell your YouTube or Drive library contents.

We do not transfer Google user data to advertisers, data brokers, or unrelated third parties for their independent use, except when required by law.

4.5 Retention and deletion

  • Revoke Google access in Google Account → Third-party access to stop further API use.
  • Sign out or use in-app Drive sign-out to clear local Drive grant flags and cached tokens where applicable.
  • Delete imported local files from the Imported library or by clearing app data / uninstalling.
  • Delete your Mixtube account in-app (where available) or email us; we remove account-linked server data according to our retention windows.

5. Data protection

  • Encryption in transit: HTTPS / TLS to Supabase, Google, and Firebase.
  • Least privilege: Google Sign-In uses read-only youtube.readonly (plus standard OpenID profile/email as needed for sign-in). Optional Google Drive import uses only drive.file with Google’s file picker — not drive.readonly.
  • On-device tokens: Google API tokens are not synced to our servers.
  • Access control: Supabase account data is scoped to the authenticated user.

6. Third parties

Mixtube relies on Apple (Sign in with Apple / App Store), Google (Sign-In, YouTube Data API, Firebase, AdMob), and Supabase (backend). Their policies apply to data they process. Streamed online media remains subject to upstream services’ terms.

7. Children

Mixtube is not directed at children under 13 (or the minimum age required in your country). We do not knowingly collect personal information from children.

8. Changes

We may update this policy from time to time. The “Last updated” date at the top will change when we do. Continued use of Mixtube after an update means you acknowledge the revised policy.
